# Hackathon demonstration

Complete the live Supabase configuration in the README first. Run the backend and frontend, then use two separate browser profiles (a normal window and an incognito window work).

1. Open the landing page. Show the original Playbit identity and the three subjects.
2. Create a student account, confirm its email if required, and sign in.
3. Choose a username, display name, avatar, subjects, and starting confidence.
4. Select Mathematics and complete the five-question diagnostic. Each answer locks immediately; correctness unlocks after the 15-second window. Show the resulting provisional rating.
5. Start a bot match. Byte is clearly labeled as simulated. Answer all five questions; observe its delayed score and the server-timed progression.
6. Show the final score, actual accuracy, response time, earned XP, and level progress.
7. Expand a wrong answer in the report. Show its formula, correct answer, recorded answer, solution steps, and possible misconception. If an AI key is configured, request revision priorities; otherwise point out the labeled verified fallback.
8. Start the recovery challenge. Complete three fresh questions in the weakest topic and show the +20 completion bonus within the earned XP.
9. Start a new round and demonstrate varied questions. Refresh mid-round to show persisted answer selection and authoritative timing.
10. Sign in as a second student in the other browser, complete their profile and Mathematics diagnostic, then create a friend room with the first student.
11. Copy the invitation or enter its six-character code. Confirm both names in the lobby, mark each player ready, and show that both screens receive identical questions and deadlines.
12. Complete the duel; refresh results to demonstrate persistence. Explain that private duels do not modify competitive Elo.
13. Open Progress, Profile, and the XP leaderboard. Subject leaderboards require five ranked games; an honest empty state is expected before anyone qualifies.
14. Optionally enter matchmaking from both accounts in the same subject to demonstrate a ranked duel and Elo changes.

The five-question rounds take roughly 78 seconds each. Use prepared, legitimately assessed accounts for a shorter presentation, but do not fabricate ratings or populate leaderboards with fictional humans.
